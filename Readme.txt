# Movie Ticket Booking Application

## Project Overview

The Movie Ticket Booking application is designed using Pega Blueprint to provide an efficient workflow for movie ticket booking.

## Workflow

The application follows these stages:

1. Submit Movie Ticket Request
2. Availability
3. Approval
4. Booking Execution

## Features

- Submit movie ticket requests
- Enter movie name
- Select show date and time
- Specify number of tickets
- Check availability
- Calculate booking cost
- Approve booking requests
- Allocate seats
- Update booking status
- Generate ticket ID

## Data Objects

- Movie
- Show
- Schedule
- Sponsor

## Personas

- Ticketing Manager
- Event Planner
- Attendee
- Vendor
- Sponsor
- Application Control Agent

## Testing

The application was successfully tested using movie booking details, including the movie "Avengers". The request successfully completed all workflow stages and displayed a successful submission confirmation.
